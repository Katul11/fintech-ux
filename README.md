# Sprout 2.0 — Fintech UI/UX Design

## Project Overview

Sprout 2.0 is a UI/UX design concept for a beginner-friendly investing app in India. The project focuses on making the investing journey clearer, more approachable, and easier to navigate for first-time investors.

## Problem Statement

The assignment identifies challenges across the user journey, including homepage bounce, KYC drop-off, uncertainty about required documents, and confusion during verification waiting periods.

## Design Goals

- Create a responsive desktop and mobile homepage.
- Design five connected mobile onboarding screens.
- Establish a consistent visual identity and Sprout mascot.
- Make KYC preparation and verification steps easier to understand.
- Support informed first-investment decisions.
- Consider accessibility, performance, and future localization.

## Screens Included

1. Desktop Homepage
2. Mobile Homepage
3. Welcome Screen
4. Investing Education Screen
5. KYC Preparation Screen
6. Verification Screen
7. First Investment Screen

## Visual Direction

The proposed design uses a forest-green and warm off-white palette, minimal typography, botanical-inspired illustrations, and a consistent component style.

## UX Focus

The project prioritizes clear communication, document preparation before KYC, transparent verification states, and a non-coercive first-investment experience.

## Project Status

UI/UX design concept. Actual implementation, accessibility validation, performance testing, and compliance review are separate steps.

## Disclaimer

This repository presents a design concept for an assignment. It does not represent a live investment service or provide financial advice.
